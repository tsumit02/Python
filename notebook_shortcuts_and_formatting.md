# Jupyter Notebook Shortcuts and Formatting

## Cell Shortcuts

| Shortcut | Action |
| --- | --- |
| `Shift + Enter` | Run the current cell and move to the next cell. |
| `Ctrl + Enter` | Run the current cell. |
| `Alt + Enter` | Run the current cell and insert a new cell below. |
| `Esc` | Enter command mode. |
| `Enter` | Edit the selected cell. |
| `A` | Insert a cell above. |
| `B` | Insert a cell below. |
| `M` | Change the cell to Markdown. |
| `Y` | Change the cell to Python code. |
| `D`, `D` | Delete the selected cell. |
| `Z` | Undo a deleted cell. |
| `Ctrl + S` | Save the notebook. |

## Markdown Formatting

### Headings

```markdown
# Main Heading
## Section Heading
### Subsection Heading
```

### Text Styles

```markdown
**Bold text**
*Italic text*
`Inline code`
```

### Lists

```markdown
- First item
- Second item

1. First step
2. Second step
```

### Links

```markdown
[Link text](https://example.com)
```

### Tables

```markdown
| Function | Description |
| --- | --- |
| `lower()` | Converts text to lowercase. |
| `upper()` | Converts text to uppercase. |
```

### Math

```markdown
Inline math: $O(n)$

$$
x^2 + y^2 = z^2
$$
```

## Cell Usage

Use Markdown cells for explanations, headings, tables, and notes.

Use Python cells for executable code:

```python
name = "John"
print(name.upper())
```
